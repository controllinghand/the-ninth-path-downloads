# The Ninth Path

*Before all things there was the Deep. Then the Speaker said one Word, and there was Light.*

An original roguelike deckbuilder. Carry the Light across the Dawnmarch as a Watcher, a Penumbra or a Lightweaver, and keep your vow.

## Installing

**Mac:** open the DMG and drag **The Ninth Path** into Applications, then open it. It's signed and checked by Apple, so it opens like any other app. (The first time, macOS may ask "downloaded from the internet. Are you sure you want to open it?": click **Open**.)

**Windows:** run the Setup file. If Windows SmartScreen warns you, click **More info** → **Run anyway**.

## Playing
- **⚙ Settings** (title screen or ☰ Menu): volume, full screen, quit. Full screen: **Ctrl+⌘+F** on a Mac, **F11** on Windows; **Esc** leaves it.
- When a new version comes out, the title menu tells you, with a button to this page.
- Your progress (stars, unlocked heroes, the Bestiary) is saved on your computer.

This page only hosts the downloads. The game is a work in progress, so expect new Days, heroes and fixes in each version.
